## 表として見るか、規則として見るか

**行列**（matrix）は、数を縦と横に長方形に並べたものです。横の並びを**行**、縦の並びを**列**と呼びます。2 行 3 列なら「2×3 の行列」と書き、「2 かける 3」と読みます。

```text
A = [ 1  2  3 ]      ← 1 行目
    [ 4  5  6 ]      ← 2 行目
      ↑  ↑  ↑
     1列 2列 3列
```

これだけなら、表計算ソフトのシートと変わりません。売上の表のように「数をしまっておく箱」として行列を使うこともあります。

しかし AI の中で行列が働くときは、たいてい別の顔をしています。**ベクトルを受け取って、別のベクトルを返す規則**という顔です。前の回の<a href={`${import.meta.env.BASE_URL}ai/ai-vector/`}>ベクトル</a>で、単語や画像が数の並び（ベクトル）として表されることを見ました。行列は、そのベクトルを別のベクトルへ移します。画像の画素の並びを「猫らしさ」「犬らしさ」の並びへ移す、というように。

この回では、この「規則としての行列」を、平面の図形を動かしながら掴みます。

## 行列とベクトルの掛け算

まず計算の手順を決めます。2×2 の行列と、2 つの数でできたベクトルを掛けます。

```text
[ a  b ] [ x ]   [ a·x + b·y ]
[ c  d ] [ y ] = [ c·x + d·y ]
```

ここで `·` は普通の掛け算です。具体的な数で一度やってみます。

```text
[ 2  1 ] [ 1 ]   [ 2·1 + 1·2 ]   [ 4 ]
[ 0  1 ] [ 2 ] = [ 0·1 + 1·2 ] = [ 2 ]
```

ベクトル (1, 2) が、この行列によって (4, 2) へ移りました。同じ計算を、2 通りの見方で読めます。

### 見方 1：行ごとの内積

答えの 1 つ目の数 4 は、行列の 1 行目 (2, 1) とベクトル (1, 2) の**内積**（成分ごとに掛けて足したもの。前の回で見た計算）です。2 つ目の数 2 は、2 行目 (0, 1) との内積です。

つまり、行列の各行は「入力のベクトルとどれだけ同じ向きか」を測る物差しで、答えはその測定値を並べたものです。行が 1000 本ある行列なら、1000 個の物差しで一度に測ることになります。ニューラルネットの中の 1 つ 1 つの「ニューロン」は、この行 1 本にあたります。

### 見方 2：列の重ね合わせ

同じ答えは、行列の**列**を使っても書けます。

```text
1 × [ 2 ] + 2 × [ 1 ]   [ 2 + 2 ]   [ 4 ]
    [ 0 ]       [ 1 ] = [ 0 + 2 ] = [ 2 ]
```

1 列目 (2, 0) を x = 1 倍、2 列目 (1, 1) を y = 2 倍して足すと、同じ (4, 2) になります。

この見方から大事なことが分かります。入力が (1, 0) なら答えは 1 列目そのもの、(0, 1) なら 2 列目そのものです。**行列の各列は、軸の向きの長さ 1 のベクトル（基本ベクトル）がどこへ行くかを書いたもの**です。そして、ほかのベクトルの行き先は、その 2 本の行き先を x 倍、y 倍して足せば決まります。

平面上のすべての点の行き先が、たった 2 本の矢印の行き先で決まってしまう。この性質を持つ変形を**線形変換**と呼びます。「線形」は、足し算と定数倍を保つという意味です（v と w を足してから移しても、別々に移してから足しても同じになる）。

### 面積の倍率：行列式

図の下に出ている**行列式**（determinant、デターミナント）は、2×2 なら `a·d − b·c` で計算できる 1 つの数で、**変形で面積が何倍になるか**を表します。

- 横に 2 倍：2·1 − 0·0 = 2。正方形の面積が 2 倍
- せん断：1·1 − 1·0 = 1。形は崩れるが、面積は変わらない
- 左右反転：(−1)·1 − 0·0 = −1。面積は同じだが、符号が負で「裏返った」ことを示す
- 線につぶす：1·1 − 2·0.5 = 0。面積が 0、つまり平面が線になった

深層学習の標準的な教科書（Goodfellow, Bengio, Courville『Deep Learning』）も、「The absolute value of the determinant can be thought of as a measure of how much multiplication by the matrix expands or contracts space. If the determinant is 0, then space is contracted completely along at least one dimension, causing it to lose all its volume.」（行列式の絶対値は、行列を掛けることで空間がどれだけ広がるか縮むかの尺度と考えられる。行列式が 0 なら、少なくとも 1 つの方向に空間が完全につぶれ、体積がすべて失われる）と説明しています（[Deep Learning, 2.11 節](https://www.deeplearningbook.org/contents/linear_algebra.html)）。

### つぶれると、戻せない

「線につぶす」の行列では、2 列目 (2, 1) が 1 列目 (1, 0.5) のちょうど 2 倍になっています。2 本の矢印が同じ直線の上に重なるので、どう組み合わせても、その直線の外へは出られません。

つぶれた後の点を見て、もとの点を当てることはできません。違う点が同じ点に重なってしまうからです。矢印が何本ぶんの方向を本当に張っているかを**ランク**と呼び、この行列のランクは 1 です。情報が失われる変形だ、と覚えておいてください。ニューラルネットでも、層の幅を急に狭くすると、ここで起きているのと同じ「つぶれ」が起き、後ろの層ではもう取り戻せません。

## 行列の掛け算は、変形を続けて当てること

変形を 2 回続けて当てたらどうなるでしょうか。まず A でせん断し、次に B で横に 2 倍にするとします。

```text
A（せん断）= [ 1  1 ]     B（横に 2 倍）= [ 2  0 ]
             [ 0  1 ]                     [ 0  1 ]
```

2 回の変形をまとめた 1 枚の行列は、**行列の積** B·A で求まります。積の計算は「左の行列の i 行目と、右の行列の j 列目の内積が、答えの i 行 j 列」です。

```text
B·A = [ 2·1 + 0·0   2·1 + 0·1 ]   [ 2  2 ]
      [ 0·1 + 1·0   0·1 + 1·1 ] = [ 0  1 ]
```

先に当てる A が**右**、後から当てる B が**左**に来ることに注意してください。ベクトル v に A を当てると A·v、それにさらに B を当てると B·(A·v) で、これを (B·A)·v とまとめたからです。

では順番を入れ替えて、先に横に 2 倍、次にせん断したら同じになるでしょうか。

```text
A·B = [ 1·2 + 1·0   1·0 + 1·1 ]   [ 2  1 ]
      [ 0·2 + 1·0   0·0 + 1·1 ] = [ 0  1 ]
```

違う行列になりました。点 (0, 1) で確かめると、B·A では (2, 1) へ、A·B では (1, 1) へ行きます。先にずらしてから伸ばすと、ずれた分まで 2 倍に伸びるからです。

図の「2 枚を重ねる」に切り替えると、A と B を選んで重ね、「順番を入れ替える」で結果が変わる様子を見られます。普通の数では 2×3 = 3×2 ですが、行列ではそうはいきません。教科書も「Matrix multiplication is not commutative (the condition AB = BA does not always hold), unlike scalar multiplication.」（行列の積は、普通の数の掛け算と違って交換法則が成り立たない。AB = BA は常には成り立たない）と書いています（[Deep Learning, 2.2 節](https://www.deeplearningbook.org/contents/linear_algebra.html)）。

一方で、3 枚以上を掛けるとき、どこから先にまとめても結果は同じです（C·(B·A) = (C·B)·A）。並べる順番は変えられないが、まとめる区切りは自由。この性質が、すぐ後で効いてきます。

## 形の約束

ここまでは 2×2 でしたが、AI で使う行列はもっと大きく、正方形とも限りません。掛け算ができるかどうかは、形で決まります。

> 左の行列の**列の数**と、右の行列の**行の数**が一致していなければ掛けられない。(m×n) と (n×p) を掛けると (m×p) になる

教科書の言い方では「In order for this product to be defined, A must have the same number of columns as B has rows. If A is of shape m × n and B is of shape n × p, then C is of shape m × p.」です（[Deep Learning, 2.2 節](https://www.deeplearningbook.org/contents/linear_algebra.html)）。

行列とベクトルの積は、その特別な場合です。ベクトルを n×1 の行列と見れば、(m×n)×(n×1) で、答えは m×1、つまり m 個の数のベクトルになります。

これは「次元を変える」ことができるということです。たとえば 28×28 画素の白黒画像は 784 個の数のベクトルです。128×784 の行列を掛ければ、128 個の数のベクトルになります。行の見方で言えば、128 本の物差しで画像を測り、その結果を並べたものです。

## ニューラルネットの 1 層：掛けて、ずらして、曲げる

ニューラルネットの 1 層は、ほとんどの場合、次の 3 つの操作でできています。

```text
y = f( W·x + b )
```

- `x`：入ってくるベクトル
- `W`：**重み**（weight）と呼ばれる行列。学習で値が決まる
- `b`：**バイアス**（bias）と呼ばれるベクトル。足すことで結果を平行にずらす。これも学習で決まる
- `f`：**活性化関数**（activation function）。成分ごとに当てる、曲がった関数

最もよく使われる活性化関数の 1 つが **ReLU**（Rectified Linear Unit、レルー）で、「負の数は 0 にし、正の数はそのまま」という関数です。`f(u) = max(u, 0)` と書きます。

小さな数で 1 層を通してみます。

```text
W = [ 1   −1  ]   b = [  0 ]   x = [ 1 ]
    [ 0.5  0.5 ]       [ −1 ]       [ 2 ]

W·x     = [ 1·1 + (−1)·2   ] = [ −1  ]
          [ 0.5·1 + 0.5·2  ]   [ 1.5 ]
W·x + b = [ −1  ]
          [ 0.5 ]
f(...)  = [ 0   ]     ← −1 は負なので 0 に
          [ 0.5 ]
```

掛ける（向きを変えて、測る）、ずらす、曲げる（負を切り捨てる）。これを何十層、何百層と重ねたものが、深層学習のモデルの骨組みです。

## なぜ「曲げる」が要るのか

ここで、ReLU のような曲げを抜いたらどうなるかを考えます。曲げのない層は `W·x + b` だけです。これを 3 層重ねると、

```text
W3·( W2·( W1·x + b1 ) + b2 ) + b3
= (W3·W2·W1)·x + (W3·W2·b1 + W3·b2 + b3)
```

と、括弧を開いて整理できます。先ほど見た「まとめる区切りは自由」という性質のおかげで、W3·W2·W1 は 1 枚の行列に、後ろの括弧は 1 本のベクトルにまとまります。**何層重ねても、1 層の `W·x + b` と同じこと**しかできないのです。

図で言えば、回転とせん断と拡大をいくら続けても、結果は 1 枚の行列による変形で、方眼は方眼のまま（まっすぐな線はまっすぐなまま、平行な線は平行なまま）です。どれだけ層を積んでも、まっすぐな線 1 本で分けられない問題は解けません。

『Deep Learning』も、2 層のネットワークの例で「if f<sup>(1)</sup> were linear, then the feedforward network as a whole would remain a linear function of its input.」（1 層目が線形なら、ネットワーク全体も入力の線形関数のままになる）と書き、続けて「Most neural networks do so using an affine transformation controlled by learned parameters, followed by a fixed nonlinear function called an activation function.」（ほとんどのニューラルネットワークは、学習されたパラメータで決まるアフィン変換の後に、活性化関数と呼ばれる固定の非線形関数を当てることでこれを実現する）としています（[Deep Learning, 6.1 節](https://www.deeplearningbook.org/contents/mlp.html)）。アフィン変換は、ここでいう「掛けて、ずらす」のことです。

### 手元で確かめる

本当に 1 枚にまとまるのかを、数値で確かめます。4 次元から 4 次元への層を 3 つ、重みとバイアスを乱数で作り、5 個の入力を通しました（Python 3.14.0、NumPy 2.5.4、Apple M1 Pro / macOS 26.2）。

```text
== 活性化なし
3 層を順に通した出力（1 個目）: [ 2.8397  3.339  10.8311 -0.9603]
1 枚にまとめた出力（1 個目）:   [ 2.8397  3.339  10.8311 -0.9603]
最大の差: 7.105427357601002e-15
```

3 層を順に通した結果と、W3·W2·W1 と整理したバイアスで 1 回だけ計算した結果が一致しました。差の 7×10⁻¹⁵ は、計算機の小数の丸め誤差です（低レイヤの<a href={`${import.meta.env.BASE_URL}lowlevel/ll-04-float/`}>浮動小数点数</a>の回で見た種類の誤差です）。

次に、1 層目と 2 層目の後ろに ReLU を挟みます。

```text
== 間に ReLU
ReLU を挟んだ出力（1 個目）: [ 2.557   0.9301  5.4335 -0.4873]
1 枚にまとめた出力との最大の差: 15.990724342477701
最も近い 1 枚（最小二乗）の残差の二乗平均: 0.6789999552910384  出力の分散: 6.531053534857762
```

もう一致しません。さらに、2000 個の入力に対して「いちばん近い 1 枚の `W·x + b`」を最小二乗法（誤差の二乗の合計が最小になるように選ぶ方法）で当てはめても、出力のばらつき 6.53 のうち 0.68 ぶんは説明しきれずに残りました。曲げを挟んだ 3 層は、どの 1 枚の行列でも表せない形をしている、ということです。

## まとめて掛けると速い

最後に、行列が AI の計算の中心にいる実務上の理由を見ておきます。

n×n の行列どうしの積は、答えの n² 個のマスそれぞれで、n 回の掛け算と足し算をします。合計でおよそ n³ 回です。n が 2 倍になると、計算は 8 倍になります。素朴に 3 重のループで書いた Python で測ると、実際にそうなりました。

```text
n=  50        9.5 ms
n= 100       42.4 ms  前の 4.4 倍
n= 200      350.9 ms  前の 8.3 倍
```

（n = 50 から 100 で 4.4 倍にとどまっているのは、小さいうちはループの外側の固定費が目立つためです。）

同じ計算を NumPy に任せると、桁が変わります。NumPy は内部で、macOS が提供する数値計算ライブラリ（Accelerate）を呼んでいます。

```text
n=  250  演算   0.03 十億回  最速     0.11 ms    288.7 GFLOP/s
n=  500  演算   0.25 十億回  最速     0.43 ms    580.2 GFLOP/s
n= 1000  演算   2.00 十億回  最速     3.42 ms    585.5 GFLOP/s
n= 2000  演算  16.00 十億回  最速    31.46 ms    508.6 GFLOP/s
```

1000×1000 の積（約 20 億回の掛け算と足し算）が 3.4 ミリ秒です。GFLOP/s は 1 秒あたり何十億回の小数の計算ができたかを表します。素朴な Python の 200×200 が 351 ミリ秒だったことと比べると、計算量で 125 倍の問題を 100 分の 1 の時間で解いています。測定中は同じマシンで別の重い処理も動いていた（ロードアベレージ 20 前後）ので、数字は目安です。

そして、AI で特に効くのが次の比較です。1000×1000 の重み行列に、入力ベクトルを 1000 個通します。

```text
1 個ずつ 1000 回: 106.8 ms  まとめて 1 回: 4.9 ms  一致: True
```

1 個ずつ行列とベクトルの積を 1000 回するより、1000 個の入力を縦に積んで 1000×1000 の行列にし、**行列と行列の積 1 回**にしたほうが、約 20 倍速くなりました。答えは同じです。

計算の回数は同じなのに速くなるのは、行列と行列の積では、重み行列の 1 つの値を、メモリから 1 回読んで何度も使い回せるからです（ベクトル 1 本ずつだと、毎回重み全体を読み直すことになる）。低レイヤの<a href={`${import.meta.env.BASE_URL}lowlevel/ll-17-cache-friendly/`}>キャッシュを意識したコード</a>の回で見た話が、ここで効いています。AI の学習や推論で入力を何十個、何百個とまとめて流す（**バッチ**処理と呼ばれます）のは、これが理由の 1 つです。この「まとめて大きな行列の積にすると速い」性質を極端まで押し進めたのが GPU で、歴史トラックの「GPU で行列積が回る仕組み」の回で詳しく見ます。

<Callout type="tip" title="実験のコード">
  ここで載せた出力は、乱数の種を 0 に固定した NumPy のスクリプトと、外部ライブラリを使わない 3 重ループのスクリプトで取りました。層の重みは標準正規分布から引いた 4×4 の行列です。種を変えると個々の数は変わりますが、「活性化なしでは差が 10⁻¹⁵ 程度、ReLU を挟むと大きく食い違う」という結論は変わりません。
</Callout>

## まとめ

- 行列は数の表であると同時に、ベクトルを別のベクトルへ移す規則。AI の中では主に後者として働く
- 行列とベクトルの積は、「行ごとの内積を並べたもの」とも「列を入力の成分倍して足したもの」とも読める。各列は、軸の向きの基本ベクトルの行き先
- 2×2 の行列で、回転、拡大、せん断、反転、つぶしが表せる。行列式は面積の倍率で、0 なら空間がつぶれて元に戻せない
- 行列の積は変形を続けて当てること。後から当てるものが左に来て、順番を入れ替えると結果が変わる。ただし、まとめる区切りは自由
- (m×n) と (n×p) を掛けると (m×p) になる。行列で次元を変えられる
- ニューラルネットの 1 層は「行列を掛けて、ずらして、曲げる」。曲げ（活性化関数）を抜くと、何層重ねても 1 枚の行列と同じになることを数値でも確かめた
- 入力をまとめて 1 回の行列と行列の積にすると、同じ計算でも大幅に速くなる

次の回では、この層の重みをどう決めるかへ向かう準備として、「入力を少し動かすと、出力がどれだけ変わるか」を測る道具、微分を扱います。
